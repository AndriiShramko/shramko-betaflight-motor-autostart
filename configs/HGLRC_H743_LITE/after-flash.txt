# Shramko Motor Autostart: board-level part of the reference setup for HGLRC_H743_LITE.
# Send after the first boot of the new firmware, USB only, battery unplugged, propeller off.
# ESC TX wire -> UART8 RX pad (PE0): function 1024 (ESC_SENSOR) on that UART, feature ESC_SENSOR.
serial UART8 1024 115200 57600 0 115200
feature ESC_SENSOR
save

# As one command:
#   python tools/bf_cli.py <PORT> "serial UART8 1024 115200 57600 0 115200" "feature ESC_SENSOR" "save"
